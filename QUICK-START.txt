LANTERN DECK 3 - QUICK START

1. Open TikTok LIVE Studio on its main studio screen.

2. Start Lantern Deck. The control center opens and a lantern icon
   appears in the taskbar tray. Closing the window keeps it running;
   quit from the tray icon.

3. Follow the setup checklist at the top of the control center:
   - LIVE Studio detected (turns green by itself)
   - Connect a phone: scan the QR code with the phone camera, open
     the link and enter the pairing code. Both devices must be on the
     same private network. The phone stays paired after restarts.
   - Assign your scenes: Edit buttons > Match scenes by name > Save.
   - Test while offline: Run studio test. It switches scenes, toggles
     the mic and desktop sound, and restores everything.
   - Go live: turn on Live control.

Until Live control is ON, buttons are only rehearsed: nothing reaches
LIVE Studio. While you are LIVE, phones ask before changing scenes.

Buttons show LIVE Studio's real state: the current scene is lit,
mute buttons say Muted or On.

If Windows asks about network access, allow Private networks only.
Do not disable your firewall or expose the app to the internet.
The phone connection uses HTTP and is meant for a trusted home network.

Settings: %LOCALAPPDATA%\LanternDeck (kept when you update or uninstall).
Problems? Control center > Diagnostics > Copy report.
