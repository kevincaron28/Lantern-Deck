LANTERN DECK 3 + MAISON PANEL

Control the streaming PC from the Deck tab of your Maison home panel.
No hotkeys or Elgato software are needed.

PAIR THE PC (once per PC):
1. Start LIVE Studio (main studio screen) and Lantern Deck on the PC.
2. On Maison Panel, open Deck > Configuration > Connecter un PC.
   Sign into the Maison owner account if asked.
3. In the Lantern Deck control center, type that eight-digit code in
   the Maison Panel card and click Connect to Maison. Codes expire
   after five minutes.
4. Turn on Live control in the control center.
5. In Maison > Deck > Configuration, choose your Starting, Gaming,
   BRB and Ending scenes. Save once.

TEST OFFLINE FIRST:
Run studio test in the control center, then try each Maison button:
check LIVE Studio's scene and mute indicators. Ending changes the
scene; it never stops the broadcast.

EVERYDAY USE:
Keep LIVE Studio and Lantern Deck running (Lantern Deck can start with
Windows from Settings). Live control starts OFF after each launch unless
you enable "Remember Live control after a restart". While it is OFF,
Maison commands are refused and nothing is queued.

MOVING TO ANOTHER PC (for example the test PC first, the streaming PC later):
Pair the new PC with a new code. Maison then forgets the old PC and its
scene choices. The credential (maison-connection.json) is encrypted for
one Windows account and does not work if copied, so never copy it.
Use "Forget this connection" in the control center, or Deck >
Configuration > Deconnecter le PC on Maison, to remove a PC.

COST AND CONNECTION:
No license fee. The Maison relay uses your Cloudflare account and the
Internet connection; free-tier limits apply. It carries only studio
status, scene names and commands, never video, camera or audio.

If something fails, the control center's Maison card and Diagnostics
say why (not paired, offline, refused, Live control OFF, scene missing).
